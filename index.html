📘 Manual de SHIFT0 2.0

Cómo usar la página

  1. Escribe un mensaje y pulsa Codificar.
  2. Para descodificar, pega el código en la sección de descodificación y pulsa Descodificar.
  3. Usa Copiar para copiar texto y Pegar para insertar lo que tengas en el portapapeles.
  4. Pulsa Usar para descodificar para transferir el resultado cifrado al campo correspondiente.
  5. El historial permite recuperar las conversiones anteriores de esta sesión.

Reglas conocidas

  • Las letras avanzan una posición en el alfabeto, con vuelta al inicio.
  • Después del desplazamiento, se toma la posición alfabética y se suma 3.
  • Mayúsculas y minúsculas usan formatos numéricos diferentes.
  • La Ñ es una letra propia, entre N y O.
  • Las vocales acentuadas llevan el prefijo 6. Ejemplo: Á = 600005.
  • Ü usa el prefijo 606. Ejemplo: Ü = 606000022.
  • Los espacios se representan con |.
  • Los dígitos se sustituyen directamente: 0→A, 1→B, 2→C, 3→D, 4→E, 5→F, 6→G, 7→H, 8→I, 9→J. Ejemplo: 2026→CACG.
  • Los símbolos usan el formato 80 + código asignado + 08. Ejemplo: ! → 80108.
  • El punto, la coma y los dos puntos permanecen sin codificar.
Nota: el algoritmo definitivo debe tener todos los códigos y formatos especificados para que la codificación y descodificación sean fiables.
